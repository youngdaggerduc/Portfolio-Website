[TITLE: Project: Radian Security Management System]
Security operations platform Pierce is building solo: one responsive app with an admin command center and a mobile guard interface. Admins draw patrol routes, place NFC/QR checkpoints and define zones on a visual map editor; guards clock in with a GPS geofence and selfie, run patrols, complete checklists and hand over shifts. It also covers incident reporting (people, vehicles, evidence, workflow, severity history), visitor / vehicle / material entry and exit logs, live GPS tracking, 12 server-evaluated alert types plus panic alerts delivered over WebSocket, and internal communications (official notices with read receipts, channels and voice rooms). Role-based permission matrix, multi-site admin, evidence stored in AWS S3, and a pytest test suite. 1,100+ commits; in active development.
Stack: React, Vite, FastAPI, Tortoise ORM, PostgreSQL, WebSockets, AWS S3. Hosted on Vercel and Render.
